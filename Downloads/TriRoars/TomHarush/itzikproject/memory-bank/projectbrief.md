# ניהול שיווק פרויקטים נדל"ניים
## Project Brief

### מטרה כללית
מערכת ניהול שיווק נדל"ן מתקדמת, מבוססת על עקרונות BIM רך - מבנה היררכי ממודל שלם אל מרכיבים שיווקיים, ללא מורכבות תכנונית־הנדסית.

### מטרות עיקריות
- ניהול דינמי של דירות, משימות וקבצים
- תצוגות תלת־ממדיות אינטראקטיביות
- תובנות שיווקיות חכמות
- ממשק מלא עם יזמים, אנשי מכירות, רוכשים וספקים
- ממשק רספונסיבי ודו-לשוני (עברית/אנגלית)

### היררכיה מרכזית (BIM רך)
```
יזם → פרויקט → בניין → קומה → דירה
```

### פרמטרים עיקריים לדירה
- מספר דירה, בניין, קומה
- שטחים (בנוי, גינה/מרפסת)
- מספר חדרים וסוג דירה
- כיווני אוויר וחזית/עורף
- חניות ומחסנים
- תמחור משולש (שיווקי, לינארי, 20/80)
- סטטוס שיווקי ואנשי קשר

### תכונות מרכזיות
1. **ניהול מסמכים לפי BIM** - טבלאות, הדמיות, מצגות, מפרטים
2. **משימות רב־שכבתיות** - היררכיה ללא הגבלה עם Kanban
3. **מודלים תלת־ממדיים** - קבצי GLB/GLTF אינטראקטיביים
4. **דשבורד ניהולי** - תובנות ונתוני ביצועים
5. **ניתוח שיווק חכם** - AI לזיהוי דפוסים ושיפורים
6. **פורטל רוכש אישי** - לינק ייחודי עם מסמכים וסטטוס
7. **דוחות אוטומטיים** - PDF/Excel ליזמים
8. **מנגנון דחיפה** - תזכורות חכמות לאנשי מכירות

### הרשאות
- מנהל מערכת, יזם, עובד יזם, איש מכירות, ספק
- הגבלות גישה לפי תפקיד ושיוך לפרויקטים

### טכנולוגיות
- **Frontend**: React, TypeScript, TailwindCSS, Zustand, i18next
- **Backend**: Supabase (DB, Auth, Storage, Realtime)
- **3D**: react-three-fiber או model-viewer
- **AI**: MCP + MemoryBank
- **Deployment**: Vercel

### Roadmap
1. **V1** - בסיס: פרויקטים, דירות, משימות, קבצים
2. **V2** - תצוגה: מודל תלת־ממד, דשבורד, תובנות
3. **V3** - שיווק: פורטל רוכש, דוחות, התראות
4. **V4** - אינטגרציות: CRM, WhatsApp, קמפיינים
